Use weighted-average inventory costing. Record unpaid sales as receivables and unpaid purchases/import costs as payables; keep journal values in ZMW using the recorded exchange rates.

**Why:** the user confirmed these choices when asked how automated accounting should treat stock cost and unpaid transactions.

**How to apply:** Maintain balanced source-linked entries, update inventory book value from receipts and allocated import costs, and do not assume cash settlement, tax treatment, or opening balances that have not been recorded.
