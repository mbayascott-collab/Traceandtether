# Using the Trade Desk Design System

- Read `../README.md` and `../tokens.css` before creating a new UI artifact for this project.
- Use the existing Trade Desk palette, typography, spacing, and component guidance as the default.
- Keep navigation, tables, forms, and status colors consistent with the guide.
- Preserve keyboard focus visibility, responsive behavior, and reduced-motion support.
- Do not edit or restyle the existing application screens unless the user explicitly approves applying this system.
- If a requested artifact needs a deliberate exception, document the reason and keep the exception local to that artifact.
